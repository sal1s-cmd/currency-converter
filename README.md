# Currency Converter

Currency converter in TypeScript. Live rates fetched from an API, clean HTML/CSS interface, built with `tsc`. No frameworks, no unnecessary dependencies.

## Features
- 10 currencies: USD, EUR, RUB, GBP, JPY, CNY, KZT, UAH, TRY, CHF
- Live rates via exchangerate-api
- Convert by button or Enter
- Auto-recalculate on currency change

## Getting started
```bash
npm install
npm run build
